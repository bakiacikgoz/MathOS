# MathOS TUI product context

MathOS is a keyboard-first mathematical research environment. Its terminal UI must let a researcher see the current objective, epistemic state, verified evidence, recent activity, and next actions without confusing activity with proof.

The primary user is a technical researcher working for long periods in a terminal. The interface should feel precise, calm, information-dense, and trustworthy. It must never invent progress, verification, or health data.

The approved wide-screen direction is a dark research cockpit with a dominant workspace, a supporting status rail, a fixed one-line command input, and a compact shortcut footer. Narrow terminals progressively collapse secondary information rather than squeezing it into unreadable columns.

Success means that the home screen is scannable, status colors are consistent, keyboard operation remains complete, long commands never increase composer height, and command suggestions never overlap surrounding content.
