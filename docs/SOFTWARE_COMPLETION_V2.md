# Software Completion V2

MathOS 1.0 RC qualification is an evidence-driven G01–G22 gate. Every gate must execute its declared command, exit successfully, bind evidence to the exact source revision, and record SHA-256 evidence. Missing, skipped, pending, stale, fake, or malformed evidence blocks `ready:true`.

The qualification covers source/version, builds, full tests, verification authority, standalone distribution, manifest/SBOM, fresh-user behavior, setup, secrets, Lean contracts, sandbox contracts, model and literature runtimes, workspace lifecycle, bridge, CLI/TUI, Atlas, VSIX, plugins, capsule/publication, update rollback, and clean-room performance.

Live paid-provider use, marketplace publication credentials, notarization credentials, and human professional-pilot review are operational evidence tracked separately; they cannot hide incomplete software gates.
