# Features

MathOS provides persistent research workspaces, claim graphs, Lean formalization and verification, governed retrieval, sandboxed experiments, literature provenance, branches, bounded multi-agent workflows, notebooks, semantic review, proof portfolios, read-only Atlas, VS Code companion, capability-safe plugins, reproducibility capsules, deterministic publication, backup/restore, diagnostics, and atomic updates.

Missing capabilities are represented as `BLOCKED` or unavailable, never as fabricated success.
