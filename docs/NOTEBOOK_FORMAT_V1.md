# Notebook format v1

MathOS Markdown uses stable block IDs, typed blocks, references, and revisions. Supported content includes prose, claims, definitions, equations, proof sketches, computations, citations, and data-only widgets. References must resolve inside the workspace; duplicate IDs and traversal fail-closed.

Notebook acceptance does not grant proof authority. Model text, computation, citations, and sketches are not proof. Only a current human-approved alignment followed by VerificationGate may produce `KERNEL_VERIFIED`. Publication includes accepted blocks only and reports broken or lossy references.

See [alignment workflow](ALIGNMENT_WORKFLOW.md) and [publication guide](PUBLICATION_GUIDE.md).
