# Publication guide

Publication Studio builds Markdown, LaTeX, or HTML from explicitly accepted notebook blocks. It preserves citations, provenance, claim references, and a loss report. Broken references block the build; incomplete evidence produces a visible watermark rather than a silent claim.

Publication does not elevate trust: narrative, citations, computations, and exported formal text are not proof. A claim is shown as `KERNEL_VERIFIED` only when current VerificationGate evidence exists. Rendering and conversion fail-closed on unsupported or unsafe content.

See [notebook format](NOTEBOOK_FORMAT_V1.md).
