# Literature ingestion

Import is additive and begins with a mutation-free dry-run. Sources retain identity, version, content hash, pages, locators, excerpts, and provider provenance. Extraction proposals are inert data until a human accepts them. Source changes stale dependent assessments and publications.

A citation, theorem-shaped excerpt, or `EXTERNAL_KNOWN` assessment is not proof and cannot grant `KERNEL_VERIFIED`. Network providers require explicit selection, HTTPS allowlists, limits, and timeout; redirects and private addresses fail-closed.

See [security model](SECURITY_MODEL_V1.md).
